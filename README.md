# Bubble Pick

A simple browser game: pick as many bubbles as you can in 45 seconds.
Small bubbles score more, gold bubbles give 25 points, and quick picks build a combo.

## Files
- `index.html` – page structure
- `style.css` – styling
- `script.js` – game logic

## Put it live with GitHub Pages
1. Create a new repository on github.com (for example `bubble-pick`), set to Public.
2. Click **uploading an existing file**, then drag in everything from this folder
   (`index.html`, `style.css`, `script.js`, `README.md`, `.nojekyll`) and click **Commit changes**.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, set Source to **Deploy from a branch**,
   choose branch `main` and folder `/ (root)`, then click **Save**.
5. Wait a minute or two. Your game will be live at
   `https://YOUR-USERNAME.github.io/bubble-pick/`

No build step or install is needed. To test locally, open `index.html` in a browser.
